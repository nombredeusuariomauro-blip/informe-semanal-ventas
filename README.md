# Automation of Jira Weekly Sales Reports

This project automates the extraction and transformation of commercial data to generate dynamic dashboards and professional weekly PDF reports.

## 🚀 Features
- **Data Ingestion:** Supports automated uploading of sales spreadsheets (Excel/CSV).
- **Interactive Dashboard:** Built with Streamlit for real-time visualization of key commercial metrics.
- **Smart Mocking:** Includes a simulation mode with automated sample data if no file is provided.
- **PDF Generation:** Formatted and optimized structure for direct stakeholder reporting.

## 🛠️ Tech Stack
- **Python 3**
- **Streamlit** (Dashboard & UI)
- **Pandas & Numpy** (Data Processing)
- **FPDF2** (PDF Automation)
